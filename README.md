# esp32s3_wifi_camera

ESP32-S3 图传相机工程，支持配网页面、MJPEG 视频流、UDP 发现和 I2C 指令交互。

## 默认行为

- 默认进入配网模式
- 配网地址：`http://192.168.1.88/`
- 视频流地址：`http://<设备IP>:81/`

## 说明

- 如果设备里已经保存过 Wi-Fi 信息，会优先尝试连接路由器
- 连接成功后，视频流使用路由器分配的 IP
- 如果没有保存 Wi-Fi，或连接失败，会回到配网模式
- 视频服务端口固定为 `81`

## 使用方法

1. 给 ESP32-S3 烧录固件
2. 连接设备创建的配网页面
3. 打开 `http://192.168.1.88/`
4. 填写 Wi-Fi 名称和密码并保存
5. 设备重启后连接路由器，使用新分配的 IP 访问视频流

## 工程结构

- `main/`：主程序、Wi-Fi、相机、网页和 UDP/I2C 功能
- `managed_components/`：`esp32-camera` 和 `esp_jpeg` 组件
- `partitions.csv`：分区表
- `sdkconfig`：当前配置
